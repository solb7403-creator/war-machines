  current Command Base site (1080,1160), which becomes the Command Gate (military look), and via fast travel/RECALL. Leaving
  returns the pilot to the gate. Banking, collection and repair work inside the plot.
- Migration: existing saves keep everything. Map today's tier (I–V) and modules (reactor, hangar, defense, vault, radar,
  uplink) onto the new buildings at equivalent levels with an auto layout, keep every current benefit (no regression), keep
  banked resources, keep Daily Base Yield. The site type defaults to RIDGE for migrated bases; the first change of site is
  free, later changes cost alloy and have a 24 h cooldown.
- Build mode: top-down camera, pinch zoom, grid snapping, rotate, move, hologram blueprint preview with valid/invalid tint
  and range rings for turrets; drones and scaffolding assemble buildings live; every level visibly changes the building.
- Unlocks by Command Center level (CC 1–10). Guided first build (one clear step at a time), never a wall of options:
  CC1 shows only what can be built now plus "next unlock at CC2".
- Buildings (each with levels, visible upgrades, real production or real effect):
  Command Center (gates tiers), Refinery (visible conveyor; minerals and salvage in, alloy out), Biodome (plants grow;
  biomass), Helium Extractor, Storage Depot (caps — production stops when full, no stockpile exploits), Reactor (power
  budget for buildings), Hangar (owned tanks on display), Science Lab (built and upgradable now; its research tree arrives in
  Session 6 — label it honestly), Trophy Hall (defeated commanders, legendary minerals, future ladder trophies), Radar,
  Uplink, Shield Generator, crew and rovers moving around the base.
- Defense you design and watch: drag-to-draw walls in mineral tiers (regolith, titanium, Armalcolite, reflective Selenite

  Defense Drill: a simulated Parasite attack on your layout you watch; no rewards (no farming); results go to a base log.
- Economy: building costs, timers, production and caps are part of this owner-approved scope; document every number in
  docs/economy/RESOURCE_ECONOMY.md. Do NOT change airdrop rules: Command Base multiplier ~x1.25, Daily Base Yield, 50,000

- Server: all build/upgrade/move/collect actions are Worker actions with validation (costs, power, footprint, caps, timers on
