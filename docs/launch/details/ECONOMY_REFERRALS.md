## Reproduced defects and contained fixes

Before fixes, local probes demonstrated: unsigned `refBy` accepted without signed invitation; signed `ref_9101` overridden by body `tg_9102`; a 90-day-old, 500,000-point account with only one active day recruited; concurrent initial syncs returned different successful inviter values and last projection write won; a linked Lunar account accepted its own Telegram alias as inviter; linked inviters were credited to a dead `tg_` alias; independent website IDs produced fake Telegram invite URLs. A later regression test also caught zero-padded direct self aliases before normalization was added.

Fixes are contained to sync/referral state in `worker/src/index.js`, invite/share behavior in `js/core.js`, canonical hydration in `js/net.js`, signed referral fixture updates in `dev/tests/wtest/test.mjs`, and the new hermetic `dev/tests/wtest/commercial-referrals.mjs`. No mechanics, prices or rewards were altered. Existing legacy inviter bindings are preserved rather than rewritten.

`node dev/tests/wtest/commercial-referrals.mjs`: **14 PASS**, exit 0.
